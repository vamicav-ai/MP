# EduReels

EduReels is a responsive learning platform combining full-length online classes with short, sequential educational reels. The Next.js application is in [`web/`](./web/).

Project documentation:

- [Product specification](./PRODUCT_SPEC.md) — a standalone description of the application, requirements, workflows, and release plan.
- [Agent development tracker](./AGENTS.md) — implementation guidance and a checklist for tracking verified development progress.
- [Web app setup](./web/README.md) — local setup, first administrator provisioning, verification commands, and current limitations.

The first release uses offline payment collection with administrator confirmation. Razorpay is a later-phase integration; no online checkout is included.
